# Prism-AI

AI-powered mock interview platform with personalized AI analysis and expert mentor review to help candidates improve their interview performance.

## Current Status

The backend foundation is currently under development, with core authentication, user management, profiles, and mentor verification workflows implemented.

## Implemented

* Student, Mentor, and Admin roles
* Student and Mentor profile management
* Admin mentor verification and rejection
* Interview domain with controlled status transitions
* PostgreSQL with JPA/Hibernate
* RESTful APIs

## Tech Stack

* Java
* Spring Boot
* Spring Security
* JWT
* Spring Data JPA / Hibernate
* PostgreSQL
* Maven


## Roadmap

* AI-powered interview execution
* Interview recording and media management
* AI-generated performance analysis
* Mentor feedback and sessions
* Real-time communication

Build a platform that combines AI-powered interview practice, structured performance analysis, and expert mentor feedback.
